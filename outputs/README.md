# Kết quả Lab 3

`exercise2/` chứa số liệu và biểu đồ được lưu từ notebook Exercise 2 trước đó. Các file này được giữ nguyên để tham khảo kết quả đã thực hiện.

Khi chạy `python main.py --output outputs/new_run`, chương trình tạo thư mục `new_run/` với metrics, history, biểu đồ, checkpoint, tokenizer và thông tin cấu hình. Thư mục này không có sẵn trong repo vì cần thực hiện quá trình huấn luyện trên máy.

Không sử dụng chung checkpoint hoặc kết quả của hai lần chạy để so sánh nếu tiêu chí chọn mô hình, seed hay dataset khác nhau.
